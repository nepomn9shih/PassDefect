# Качество кода (общие принципы)

Применяется ко всему коду проекта.

## Синтаксис ES6+

- Использовать `const`/`let` вместо `var`.
- Использовать стрелочные функции, деструктуризацию, spread-операторы.
- Использовать `import`/`export` вместо `require`.

## Чистота кода

- Избегать дублирования (DRY).
- Уменьшать цикломатическую сложность: разбивать сложные функции на более мелкие.
- Максимально упрощать логику условий.

## Инструменты

- Линт: ESLint 9 (flat config в `eslint.config.js`, `typescript-eslint`, плагины `react-hooks` и `react-refresh`). Запуск — `npm run lint`.
- Prettier не установлен: при правках следовать локальному стилю файла (табуляции/indentation), а не перекодировать весь файл.
