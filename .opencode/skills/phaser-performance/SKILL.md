# Phaser.js: производительность

## Управление объектами и физика

- Использовать `container`, `group` для управления объектами; включать `group.runChildUpdate = true`, чтобы дети обновлялись сами (паттерн `MainScene.createGroups()`).
- Дебажить производительность через `Phaser.Debug`.
- Избегать создания объектов в `update()`.
- Использовать `getFirstDead()` и переиспользование объектов вместо постоянного создания/уничтожения; ограничивать размер пула через `group.maxSize`, чтобы число сущностей не росло бесконечно.
- Culling: не обновлять и скрывать (`setActive(false).setVisible(false)`) сущности вне видимой области камеры — критично при большом числе монстров; повторную активацию делать при входе в область.
- Отключать физику неактивных тел (`body.enable = false`) вместо их удаления — тело можно вернуть одним флагом.
- В `physics.add.collider` / `physics.add.overlap` передавать `processCallback` для дешёвой фильтрации пар до вызова полного коллбека (например, проверка дистанции/флага).
- Оптимизировать коллизии: группировать статические объекты в `StaticGroup`, использовать `overlap` только при необходимости.
- Использовать `setVelocity` вместо прямого изменения `x`/`y` для физических объектов.
- Минимизировать вызовы `setFrame`, `setTexture`, `setDepth` — кэшировать значения при частом использовании.
- Не рисовать через `this.add.graphics()` каждый кадр (clear/fill) — статичные декорации запекать в `RenderTexture`, а графику менять только при изменении значения (как в прогресс-баре `BootScene`).
- `setInteractive()` навешивать только на кликабельные объекты; при переходах/паузе снимать интерактив через `disableInteractive()`, чтобы не тратить hit-testing.
- Использовать `Phaser.Math.Distance.Between` и `Phaser.Math.Angle.Between` для оптимизированных вычислений.
- Выносить тяжёлые операции (например, поиск пути) в отдельные таймеры или воркеры, если возможно.

## Таймеры и AI

- Заменить `setInterval`/`setTimeout` на `this.time.addEvent()` — встроенный таймер Phaser, интегрированный с игровым циклом, безопасный при паузе/остановке сцены.
- Использовать `this.time.delayedCall()` вместо `setTimeout(..., 0)` — обеспечивает синхронизацию с кадрами и корректную работу при изменениях скорости игры.
- Оптимизировать частоту обновлений AI монстров — не обновлять каждый кадр, а использовать таймеры (например, раз в 500–1000 мс), особенно для игр в стиле Vampire Survivors с большим количеством врагов.
- Упрощать логику `update()` — выносить нетребовательные к частоте обновления операции в отдельные методы с таймерами.
- Использовать `Phaser.Utils.Array.GetRandom()` для эффективного выбора случайных элементов.
