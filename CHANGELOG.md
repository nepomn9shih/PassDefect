# Changelog

Все значимые изменения проекта PassDefect описываются в этом файле.

## 1.2.0 — 2026-10-27

Оптимизация производительности движка: отсеяли работу, которая не даёт наблюдаемого эффекта — перерисовку шкал здоровья, поворот оружия без смены направления, обработку выключенных физических тел и бесцельный рескейл канваса. Ориентация оружия при переключении отныне выставляется верно.

### Fixed

- Оружие оставалось ненаправленным после смены (HUD/шифт/реюз монстра), пока игрок впервые не повернётся: create-методы задавали только смещение, а углы и отражения применялись поворотом. Ориентация вынесена в `applyDirection()`, она вызывается при создании и пересоздании оружия.
- Рескейл канваса срабатывал на каждый тик зума впустую: зум меняет только трансформ камеры, размер окна не меняется. Обработчик зума больше не вызывает rescale.
- Рескейл канваса стрелял на каждый кадр при перетаскивании окна — добавлен дебаунс 100 мс.

### Changed

- Шкала здоровья монстра — ребёнок контейнера: следует за монстром бесплатно, перерисовка только при изменении здоровья (раньше clear+fillRect каждый кадр).
- Поворот оружия выполняется только при смене направления движения владельца вместо каждый кадр.
- Выключенные тела (`body.enable = false`) у неактивных монстров, сундуков и бездействующих снарядов: физика пропускает их целиком, включая проверку пар «монстр ↔ монстр» (раньше неактивные тела всё равно проходили цикл обновления).
- Подбор сундука и получение урона проходит через `processCallback` коллизий: гварды («полный запас», «неактивный снаряд») отсеиваются до вызова обработчика.
- Блокеры карты переведены на статические тела (`StaticGroup`): сотни неподвижных объектов больше не интегрируются физикой каждый кадр.

## 1.1.0 — 2026-10-27

Ревью игровой механики и первая волна исправлений: устранены утечки памяти, баги переиспользования объектов и рассинхрон с Redux. Функциональность игры не изменилась.

### Added

- Юнит-тесты для утилит `engine/utils` (9 файлов, 58 тестов: спавн наград, зум, уровни игрока, импорт ассетов, свойства Tiled, конфиг игры, rescaleHandler).

### Fixed

- Реюз монстра из пула: вариация теперь берётся из модели, при реюзе обновляются текстура, статы и оружие (раньше спрайт мог остаться от другой вариации).
- Анимации монстров: ключи включают вариацию (`monster-knight-move`), создание защищено guard `anims.exists` — при добавлении нового вида монстров анимации не смешиваются.
- Респавн игрока: контейнер переиспользуется вместо создания нового — исчезли утечки спрайтов и накопление физ-коллайдеров (`addCollisions` вызывается один раз).
- Полный сброс игрока при респавне: оружие → дефолтный SWORD (раньше оставалось выбранное на момент смерти), шлем, направление взгляда, `damageCooldown`.
- Скорость игрока при респавне восстанавливается по уровню (раньше оставалась от уровня на момент смерти).
- Таймер движения монстра ставится на паузу у неактивных монстров — мёртвые монстры больше не расходуют игровой цикл.
- Утечки подписок: все слушатели `scene.events` снимаются по `shutdown`; `window.addEventListener('resize')` заменён на `scale.on(Phaser.Scale.Events.RESIZE)`.
- Redux: переключение оружия в сцене срабатывает только при изменении weapon-слайса; убран двойной dispatch наград за убийство монстра.

### Changed

- Единая точка копирования параметров: `applyPlayerParams`/`applyMonsterParams` вызываются и при создании, и при респавне/реюзе — новый параметр модели автоматически попадает во все пути.
- Конструкторы `PlayerContainer`/`MonsterContainer` принимают модель целиком вместо перечисления полей.
