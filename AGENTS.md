# Руководство для AI-агентов (Phaser.js, React, TypeScript)

Проект использует стек: **Phaser.js**, **React**, **TypeScript**, **styled-components**, **Redux Toolkit**.

Цель — повысить читаемость, поддерживаемость, расширяемость и производительность кода без изменения его функциональности.

## Скиллы с правилами по темам

Detальное описание стандартов вынесено в скиллы `.opencode/skills/*/SKILL.md`, загружай соответствующий скилл при работе с соответствующей темой:

| Скилл | Когда применять |
| --- | --- |
| `code-quality` | любой код, рефакторинг, чистота и стиль (ES6+) |
| `typescript-style` | любой код `.ts`/`.tsx`, типы, интерфейсы |
| `react-components` | React-компоненты, хуки, styled-components, ререндеры |
| `phaser-scenes-and-assets` | сцены Phaser, жизненный цикл, ассеты |
| `phaser-performance` | `update()`, таймеры, AI, коллизии, пулинг |
| `phaser-react-integration` | монтирование Phaser в React, обмен состоянием |
| `redux-toolkit` | слайсы, thunks, состояние игры |
| `testing-jest-rtl` | тесты на Jest + React Testing Library |

## Работа AI-агента

При внесении изменений AI-агент должен:

1. **Анализировать контекст** перед редактированием.
2. **Разбивать сложные функции** на более мелкие.
3. **Устранять дублирование** через вынесение в утилиты или хуки.
4. **Типизировать всё**, что не типизировано — см. скилл `typescript-style` (запрещён `any`).
5. **Использовать хуки React** вместо классов.
6. **Оптимизировать ререндеры** через `React.memo`, `useCallback`, `useMemo` — см. скилл `react-components`.
7. **Следить за производительностью** Phaser (не создавать объекты в `update`).
8. **Сохранять функциональность** — не менять поведение приложения.
9. **Форматировать код** согласно ESLint (`npm run lint`) — см. скилл `code-quality`.
10. **Проверять, что новые компоненты и хуки имеют минимальную зависимость от внешних данных**, используют пропсы и колбэки.

> ⚠️ **Важно**: AI-агент не должен вносить изменения, выходящие за рамки текущей задачи. Все изменения должны быть минимально инвазивными и целенаправленными.
